## 固定流程：对话内回编号打勾
收到罗斌“✅ A1 B3 K2…”后，清单专家依次做：
0. **每次动手前先重新读正本**：罗斌可能已在 Claude App 里直接改过（自己把 [ ] 改成 [x]、加删条目）。发现手改内容照单接受：补编号（新增项按区末续号）、升版、刷新时间，再重建 push。
1. 读最新 MD；把对应编号的 `- [ ]` 改成 `- [x]`（编号不存在/已勾则回报，不猜）。
2. 升版本号（v1.9→v2.0…小改动 +0.1）+ 刷新“📌 版本”行时间（Sydney，到分钟）。**只升版本号+刷新时间，不写更新记录（罗斌 2026-11-15 定）。**
3. `python3 tools/build_page.py` 重建 index.html（保留 robots.txt 与 noindex）。
4. `git add -A && git commit -m "vX.Y 勾选…" && git push`。
5. 回报对话视图：按分区“已完成/总数”，今天要办的区放最前，☐/☑ + 编号 + ≤12 字名称；顶部给总进度。
6. 同一件事不拆成两项；发现拆分即合并（罗斌 2026-11-15 定）。合并保留主位置编号，被并编号作废不复用，信息写全；拿不准的列给总管家问罗斌。
7. 每次回报必须同时给 MD 正本链接和 HTML 网页链接（https://robin12300-snailai.github.io/overseas-checklist-2026-11/），以及点 ▶ 可运行的打开命令：open "<正本绝对路径>"（罗斌 2026-11-15 定）。
8. **合并规则最终口径**（罗斌授权总管家/清单专家，2026-11-15）：按“同一动作 + 同一物品”判断是否合并；明显同一件事直接合并并告知，拿不准的才问罗斌。已定不合并：A5/A6 与 N1、A6 与 L2。
撤销用“↩ 编号”：改回 `[ ]`，同样升版。新增条目：接在该区末尾续号（不写更新记录）。
