## 固定流程：对话内回编号打勾
收到罗斌“✅ A1 B3 K2…”后，清单专家依次做：
0. **每次动手前先重新读正本**：罗斌可能已在 Claude App 里直接改过（自己把 [ ] 改成 [x]、加删条目）。发现手改内容照单接受：补编号（新增项按区末续号）、升版、刷新时间、更新记录注明“罗斌手改”，再重建 push。
1. 读最新 MD；把对应编号的 `- [ ]` 改成 `- [x]`（编号不存在/已勾则回报，不猜）。
2. 升版本号（v1.9→v2.0…小改动 +0.1）+ 刷新“📌 版本”行时间（Sydney，到分钟）+ 更新记录顶部追加一行（如“勾选 A1 B3 K2”）。
3. `python3 tools/build_page.py` 重建 index.html（保留 robots.txt 与 noindex）。
4. `git add -A && git commit -m "vX.Y 勾选…" && git push`。
5. 回报对话视图：按分区“已完成/总数”，今天要办的区放最前，☐/☑ + 编号 + ≤12 字名称；顶部给总进度。
撤销用“↩ 编号”：改回 `[ ]`，同样升版。新增条目：接在该区末尾续号，记入更新记录。
